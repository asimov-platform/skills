# ASIMOV Skills

[Agent Skills](https://agentskills.io/) for [ASIMOV](https://github.com/asimov-platform), the open-source personal intelligence platform: installable modules turn your data sources, personal and public, into a context graph connecting the people and information in your life. Installing the skill teaches your agent to set up and drive the [ASIMOV CLI](https://github.com/asimov-platform/asimov-cli).

## Skills

| Skill                    | Teaches                                                            |
| ------------------------ | ------------------------------------------------------------------ |
| [asimov](skills/asimov/) | Find, install, and configure modules; retrieve knowledge with them |

## Installation

Use the [skills CLI](https://skills.sh/) to install them in any supported harness:

```bash
npx skills add asimov-platform/skills
```

Or just ask your agent:

```text
Install the ASIMOV Platform for me: https://github.com/asimov-platform/skills
```
